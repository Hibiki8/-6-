# ストリートファイター6 統計ウェブサイト

このプロジェクトは、ストリートファイター6に関する統計情報やキャラクター情報を提供するウェブサイトです。

## プロジェクト構成

- **css/**: スタイルシートを格納するフォルダー
  - `reset.css`: ブラウザのデフォルトスタイルをリセットするためのCSSスタイルシート
  - `style.css`: プロジェクト全体のスタイルを定義するCSSスタイルシート

- **js/**: JavaScriptファイルを格納するフォルダー
  - `main.js`: プロジェクトのメインJavaScriptファイル。インタラクティブな機能や動的なコンテンツを管理します。

- **pages/**: 各種HTMLページを格納するフォルダー
  - `characters.html`: キャラクターに関する情報を表示するHTMLページ
  - `rankings.html`: ランキング情報を表示するHTMLページ
  - `statistics.html`: 統計情報を表示するHTMLページ

- **fonts/**: プロジェクトで使用されるフォントファイルを格納するためのフォルダー（現在は空です）

- `index.html`: プロジェクトのメインHTMLページ。サイトの入り口として機能します。

## 使用方法

1. プロジェクトをクローンまたはダウンロードします。
2. `index.html`をブラウザで開きます。
3. 各ページにアクセスして、キャラクター情報やランキング、統計情報を確認します。
