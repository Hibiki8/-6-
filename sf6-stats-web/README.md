# ストリートファイター6 統計ウェブサイト

このプロジェクトは、ストリートファイター6に関する統計情報を表示するためのウェブサイトです。以下のファイルとフォルダが含まれています。

## ファイル構成

- **css/**
  - `reset.css`: ブラウザのデフォルトスタイルをリセットするためのCSSスタイルシートです。
  - `style.css`: サイト全体のスタイルを定義するCSSスタイルシートです。フォントファミリーやレイアウトに関するスタイルが含まれています。

- **js/**
  - `main.js`: サイトのメインJavaScriptファイルで、DOM操作やイベントリスナーの設定など、サイトのインタラクティブな機能を実装します。
  - `data.js`: データの取得や管理を行うためのJavaScriptファイルです。APIからのデータ取得や、データの加工に関する関数が含まれています。

- **fonts/**: サイトで使用するフォントファイルを格納するためのフォルダです。現在は空です。

- **pages/**
  - `characters.html`: キャラクターに関する情報を表示するためのHTMLページです。
  - `rankings.html`: ランキング情報を表示するためのHTMLページです。
  - `statistics.html`: 統計情報を表示するためのHTMLページです。

- **index.html**: サイトのホームページで、他のページへのリンクや基本的なコンテンツが含まれています。

## 起動方法

Spring Boot アプリケーションはクローンしたフォルダーのルートから起動します。コマンドは親フォルダーの README を参照してください。このサブフォルダー内のページとアセットも `/sf6-stats-web/` 以下で配信されます。

## 開発

フロントエンドは HTML、CSS、JavaScript で構成されています。必要に応じて、各ファイルを編集して機能を追加したり、スタイルを変更したりできます。
